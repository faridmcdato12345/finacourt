# FinACourt silent brand promo

Two output formats are rendered from real FinACourt product footage:

- `finacourt-brand-promo-16x9-silent.mp4` — 1920×1080 for website, YouTube, and landscape placements.
- `finacourt-brand-promo-9x16-silent.mp4` — 1080×1920 for Reels, Stories, and TikTok.

Both cuts are intentionally silent: no narration, music, subtitles, captions, or burned promotional copy.

| Approx. time | Visual story |
| --- | --- |
| 0–4s | Owner dashboard paired with player discovery: operations and discovery connect. |
| 4–8s | Promotion controls paired with the live player schedule. |
| 8–12s | Loyalty settings paired with the player booking experience. |
| 12–16s | Player discovery in a phone frame. |
| 16–20s | Player live schedule: choose a court and available time. |
| 20–24s | Player bookings: the game pass and return experience. |
| 24–27s | Logo-only FinACourt end card. |

The app UI supplies all visible product text. No video-specific text is superimposed.
